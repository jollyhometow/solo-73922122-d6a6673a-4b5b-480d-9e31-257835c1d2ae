推荐演示流程

      
    
        
  1. 点「一键准备演示数据」，到 Tab① 查看 S1002（2026-03-31）当前挂「华东」，S1008 落空档未归属，C003 全部 no_timeline。
    2. 
        
  2. Tab② 载入 C001 追溯更正模板，回填延迟设 8000ms，提交；立刻回 Tab① 持续刷新——回填期间仍可导入销售、查询旧结果。
    3. 
        
  3. 回填进行中再上传一次 CSV（重复 ID 跳过）或新增销售，验证切换事务会把期间新增销售一并纳入。
    4. 
        
  4. 同一客户并发提交第二份更正：第二份返回 409（互斥）；改旧 expected_version 提交则 409 stale_version。
    5. 
        
  5. 任务成功后 S1002 改挂「华南」，时间线/销售归属同为 v2；勾选「模拟回填失败」可验证失败后旧版完整保留。
    6. 
        
  6. 命令行：docker compose restart web1 web2 后数据与版本仍在；两个入口 :8081 / :8082 由 nginx :8080 负载均衡。
    7.
